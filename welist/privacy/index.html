2. 수집하는 개인정보 항목 및 수집 방법

WeList는 가족·룸메이트 등이 그룹을 만들어 장보기·생활 목록을 함께 쓰는 서비스입니다. 이를 위해 Google 계정으로 로그인하며, 이용자 정보와 목록 데이터는 처리자가 이용하는 클라우드 서비스(Supabase)의 서버에 저장·동기화됩니다.

2.1 로그인 시 수집하는 정보

구분 항목 수집 방법
계정 정보 이메일 주소, 계정 고유 식별자(UUID) Google 로그인 시 Google이 발급한 ID 토큰을 Supabase Auth가 확인하여 생성
프로필 정보 표시 이름(Google 계정 이름, 없으면 이메일 앞부분), 프로필 사진 URL Google 계정 정보(email, profile 범위)에서 자동 저장
인증 정보 로그인 세션 토큰 Supabase Auth가 발급하여 기기에 보관

같은 그룹의 멤버에게는 이용자의 표시 이름·프로필 사진과 이용자가 작성·완료한 항목 정보가 표시됩니다.

2.3 서비스 이용 과정에서 다루는 정보

항목 설명
네트워크 서버 통신을 위해 인터넷 권한만 사용합니다. 서버 접속 시 IP 주소 등 접속 기록이 Supabase 인프라의 로그에 남을 수 있으며, 이는 서비스 운영·보안 목적에 필요한 기간 동안 Supabase 정책에 따라 보관된 뒤 삭제됩니다.
실시간 동기화 목록·항목 변경을 다른 멤버에게 실시간으로 반영하기 위해 Supabase Realtime을 사용합니다.
클립보드 이용자가 ‘복사’를 누른 경우에만 초대 코드를 클립보드에 복사합니다.

처리자는 현재 버전에서 광고 SDK(AdMob 등), 분석(Analytics)·크래시 리포트 SDK, 원격 푸시 알림(FCM), 인앱 결제 SDK를 사용하지 않습니다. 알림·위치·카메라·연락처·사진 권한도 요청하지 않습니다.

3. 개인정보의 이용 목적

  1. 회원 식별 및 로그인: Google 로그인으로 계정을 만들고 본인을 확인하기 위함
  2. 공유 목록 제공: 그룹 생성·초대·참여, 목록·항목 작성과 완료 표시, 멤버 간 실시간 동기화
  3. 멤버 표시: 같은 그룹 멤버에게 표시 이름·프로필 사진, 작성자·완료자 표시
  4. 그룹 관리: 초대 코드 발급·재발급, 멤버 내보내기, 그룹 나가기·삭제
  5. 보안 및 부정 이용 방지: 그룹 멤버만 데이터에 접근하도록 하는 권한 확인
  6. 고객 문의 대응: 이메일로 접수된 문의·권리 행사 요청 처리

4. 개인정보의 보유 및 이용 기간·파기

  • 보유 장소: Supabase 클라우드 서버(일본 도쿄 리전). 6. 국외 이전 참고.
  • 보유 기간: 회원 탈퇴(계정 삭제) 시까지 보관하며, 탈퇴 시 지체 없이 파기합니다. 관련 법령에 따른 보관 의무가 있으면 해당 기간 동안 보관합니다.
  • 그룹 삭제: 그룹장이 그룹을 삭제하면 해당 그룹의 멤버 정보, 목록, 항목, 카테고리가 함께 삭제됩니다.
  • 그룹 나가기·내보내기: 멤버 관계는 삭제되지만, 이용자가 그룹에 작성한 목록·항목은 그룹에 남을 수 있습니다(작성자 표시는 계정 삭제 시 비워집니다).
  • 계정 삭제: 계정을 삭제하면 프로필과 그 이용자가 그룹장인 그룹(목록·항목 포함)이 삭제되고, 다른 그룹에 남긴 항목의 작성자·완료자 정보는 비워집니다.
  • 문의 이메일: 문의 처리에 필요한 범위에서 보관하고 목적 달성 후 지체 없이 파기합니다.
  • 파기 방법: 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

5. 개인정보의 제3자 제공

처리자는 이용자의 동의 없이 개인정보를 외부에 판매하거나 마케팅 목적으로 제공하지 않습니다. 다만 법령에 근거한 요청이 있는 경우 등 관련 법률이 허용하는 범위에서는 제공될 수 있습니다.

서비스 특성상 이용자가 같은 그룹에 참여한 다른 멤버에게 표시 이름, 프로필 사진, 이용자가 작성·완료한 목록과 항목이 공개됩니다. 이는 이용자가 초대 코드로 그룹에 참여하여 발생하는 서비스의 기본 기능입니다.

8. 아동의 개인정보 보호 (만 14세 미만)

서비스는 만 14세 이상 이용자를 대상으로 하며, 만 14세 미만 아동을 주요 대상으로 설계·홍보하지 않습니다. 처리자는 이용자의 나이를 묻거나 수집하지 않습니다.

「개인정보 보호법」에 따라 만 14세 미만 아동의 개인정보를 처리하려면 법정대리인의 동의가 필요합니다. 만 14세 미만 아동은 법정대리인의 동의를 받아 이용해 주시기 바랍니다. 처리자가 법정대리인 동의 없이 아동의 개인정보를 수집한 사실을 확인하면 해당 계정과 정보를 지체 없이 파기합니다. 열람·삭제·문의는 위 이메일로 연락해 주세요.

9. 광고

서비스는 현재 광고와 유료 기능이 없으며, 광고 SDK를 포함하지 않습니다. 향후 광고나 유료 기능을 도입하는 경우 본 방침과 Play Data Safety를 개정한 후 사전에 공지합니다.

10. 개인정보의 안전성 확보 조치

  • 전송 구간 암호화(HTTPS)를 통한 서버 통신
  • 데이터베이스 행 수준 보안(RLS): 같은 그룹 멤버만 그룹·목록·항목을 조회·수정할 수 있도록 접근 제한
  • 그룹 관리 기능(초대 코드 재발급, 멤버 내보내기, 그룹 삭제)은 그룹장만 실행 가능
  • 비밀번호를 직접 저장하지 않는 Google 로그인 사용
  • 분석·광고 등 불필요한 SDK 미사용

다만 인터넷·모바일 환경 특성상 완벽한 보안을 보장할 수는 없습니다. 이용자도 기기 잠금과 초대 코드 관리에 유의해 주세요. 초대 코드를 아는 사람은 누구나 그룹에 참여할 수 있으므로, 코드가 노출되면 그룹장이 재발급해 주세요.
